# Yi UI 原型

## 文件

- `yi-prototype.html`：可交互的面对面对话原型，可直接用浏览器打开。
- `yi-main-screen.svg`：GitHub 可直接预览的主界面静态图。
- `../../design-system/yi/MASTER.md`：全局设计系统。
- `../../design-system/yi/pages/conversation.md`：面对面对话页专用覆盖规则。

## 交互说明

1. 在页面顶部选择英语、日语或韩语。
2. 点击“开始对话”。
3. 使用原型底部的“下一状态”依次查看监听对方、中文播报、监听用户和外语播报。
4. 点击中央方向按钮可模拟识别方向纠错。

本原型用于确认布局、视觉层级和状态反馈，不会访问麦克风、网络或任何云服务。
